# Java OOP Learning Pack
## 10 Java Programs with UML Class Diagrams

### Program 1: Class and Object

**Aim:** To create a class and object in Java.

**UML Diagram:**
```text
+----------------------+
|       Student        |
+----------------------+
| + name: String       |
+----------------------+
| + display(): void    |
+----------------------+
```

**Java Program:**
```java
class Student {
    String name = "Arun";

    void display() {
        System.out.println(name);
    }

    public static void main(String[] args) {
        Student s = new Student();
        s.display();
    }
}
```

**Output:** `Arun`

### Program 2: Encapsulation

**Aim:** To demonstrate private data and a public getter.

**UML Diagram:**
```text
+-------------------------+
|       BankAccount       |
+-------------------------+
| - balance: int          |
+-------------------------+
```

```java
class BankAccount {
```

### Program 4: Method Overloading

**Aim:** To demonstrate compile-time polymorphism.

**UML Diagram:**
```text
+------------------------+
|      Calculator        |
+------------------------+
| + add(int,int): int    |
| + add(int,int,int): int|
+------------------------+
```

**Java Program:**
```java
class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();
        System.out.println(c.add(2, 3));
        System.out.println(c.add(2, 3, 4));
    }
}
```

**Output:**
```text
5
9
```

### Program 5: Method Overriding

**Aim:** To demonstrate runtime polymorphism.

**UML Diagram:**
```text
+------------------+
|      Animal      |
+------------------+
| + sound(): void  |
+------------------+
         ▲
         |
+------------------+
|        Dog       |
+------------------+
| + sound(): void  |
+------------------+
```

**Java Program:**
```java
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }

    public static void main(String[] args) {
        Animal a = new Dog();
        a.sound();
    }
}
```

**Output:** `Bark`

### Program 8: Association

**Aim:** To demonstrate a relationship between independent objects.

**UML Diagram:**
```text
+-----------+       +-----------+
|  Teacher  |-------|  Student  |
+-----------+       +-----------+
| + teach() |       | + learn() |
+-----------+       +-----------+
```

**Java Program:**
```java
class Teacher {
    void teach() {
        System.out.println("Teaching");
    }
}

class Student {
    void learn(Teacher t) {
        t.teach();
    }

    public static void main(String[] args) {
        Teacher t = new Teacher();
        Student s = new Student();
        s.learn(t);
    }
}
```

**Output:** `Teaching`

### Program 9: Aggregation

**Aim:** To demonstrate a whole-part relationship with independent objects.

**UML Diagram:**
```text
+-------------+     ◇------ +----------+
| Department  |             | Teacher  |
+-------------+             +----------+
| - teacher   |             | - name   |
+-------------+             +----------+
```

**Java Program:**
```java
class Teacher {
    String name;

    Teacher(String name) {
        this.name = name;
    }
}

class Department {
    Teacher teacher;

    Department(Teacher teacher) {
        this.teacher = teacher;
    }

    public static void main(String[] args) {
        Teacher t = new Teacher("Ravi");
        Department d = new Department(t);
        System.out.println(d.teacher.name);
    }
}
```

**Output:** `Ravi`

### Program 10: Composition

**Aim:** To demonstrate object ownership.

**UML Diagram:**
```text
+-----------+     ◆------ +----------+
|    Car    |             |  Engine  |
+-----------+             +----------+
| - engine  |             | + start()|
+-----------+             +----------+
```

**Java Program:**
```java
class Engine {
    void start() {
        System.out.println("Engine started");
    }
}

class Car {
    private final Engine engine = new Engine();

    void startCar() {
        engine.start();
    }

    public static void main(String[] args) {
        new Car().startCar();
    }
}
```

**Output:** `Engine started`

## Conclusion

These ten Java programs demonstrate fundamental OOP concepts, including classes, encapsulation, inheritance, polymorphism, abstraction, interfaces, and object relationships. The UML diagrams represent the basic structure and relationships of the classes.
