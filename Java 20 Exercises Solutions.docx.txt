# Java OOP Learning Pack
## 20 Java Practice Exercises with Solutions

### Exercise 1: Create a Class
**Question:** Create a `Student` class with a `display()` method.

**Solution:**
```java
class Student {
    void display() {
        System.out.println("Student details");
    }

    public static void main(String[] args) {
        new Student().display();
    }
}
```
**Output:** `Student details`

### Exercise 6: Method Overloading
**Question:** Create two `add()` methods with different parameter lists.

**Solution:**
```java
class Add {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        Add a = new Add();
        System.out.println(a.add(2, 3));
        System.out.println(a.add(1, 2, 3));
    }
}
```
**Output:**
```text
5
6
```

### Exercise 7: Method Overriding
**Question:** Override a method in a subclass.

**Solution:**
```java
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }

    public static void main(String[] args) {
        new Dog().sound();
    }
}
```
**Output:** `Bark`

### Exercise 17: Demonstrate Aggregation
**Question:** Pass an existing `Teacher` object to a `Department`.

**Solution:**
```java
class Teacher {
    String name = "Ravi";
}

class Department {
    Teacher teacher;

    Department(Teacher t) {
        teacher = t;
    }

    public static void main(String[] args) {
        Teacher t = new Teacher();
        Department d = new Department(t);
        System.out.println(d.teacher.name);
    }
}
```
**Output:** `Ravi`

### Exercise 18: Demonstrate Composition
**Question:** Create an `Engine` inside a `Car`.

**Solution:**
```java
class Engine {
    void start() {
        System.out.println("Engine started");
    }
}

class Car {
    private final Engine engine = new Engine();

    public static void main(String[] args) {
        new Car().engine.start();
    }
}
```
**Output:** `Engine started`
